# Tastenkürzel

[Zurück zum Inhalt](index.md)

**Super+?** öffnet das Programm „Tastenkürzel“ (Anwendungen → Zubehör). Es
liest die Kürzel aus der Fensterverwalter-Konfiguration der laufenden
Sitzung und zeigt auf zwei Reitern „Arbeitsfläche“ und „Programme“ alles,
was gerade gilt. Esc oder Strg+W schließt es.

„Super“ ist die Windows-Taste.

## Sitzung und Fenster

| Kürzel | Wirkung |
|---|---|
| Druck | Bildschirmfoto: Auswahl Bildschirm, Fenster oder Bereich |
| Alt+Druck | Bildschirmfoto eines Fensters |
| Strg+Alt+L | Bildschirm sperren |
| Strg+Alt+Entf | Sitzungsdialog (Abmelden, Bildschirm sperren, Neu starten, Herunterfahren) |
| Super+? | Übersicht der Tastenkürzel |
| Strg+Alt+← / → | Arbeitsfläche links / rechts |
| Strg+Alt+Umschalt+← / → | aktives Fenster auf die Arbeitsfläche links / rechts mitnehmen |
| Alt+Tab / Alt+Umschalt+Tab | nächstes / voriges Fenster |
| Alt+F4 | Fenster schließen |
| Super+A | Fenster maximieren / zurück |
| Super+←, →, ↑, ↓ | Fenster an den Rand andocken |
| Alt+Leertaste | Fenstermenü |
| Super+Eingabe | Terminal öffnen (Standardbelegung von labwc) |
| Lautstärke- und Helligkeitstasten | lauter, leiser, stumm; heller, dunkler (soweit die Hardware sie meldet) |

## Programme

Die Kürzel der Programme stehen auch auf deren Seiten. Kurzfassung:

**Arbeitsfläche:** F2 umbenennen · Strg+A alle auswählen · Esc Auswahl
aufheben · Strg+Klick und Umschalt+Klick Mehrfachauswahl.

**Querencia Files:** Strg+N neues Fenster · Strg+T neuer Reiter · Strg+W
Reiter schließen · Strg+Umschalt+N neuer Ordner · Strg+X/C/V
Ausschneiden/Kopieren/Einfügen · Strg+D duplizieren · Strg+Z/Strg+Umschalt+Z
rückgängig/wiederholen · F2 umbenennen · Alt+Eingabe Eigenschaften ·
Umschalt+Entf endgültig löschen · Strg+K suchen · Strg+L Ort eingeben · Strg+R
neu laden · Strg+B Seitenleiste · Strg+, Einstellungen · Alt+←/→ zurück/vor ·
Alt+↑ übergeordneter Ordner · Alt+Pos1 Persönlicher Ordner.

**Querencia Terminal:** Strg+Umschalt+C kopieren · Strg+Umschalt+V oder
Umschalt+Einfg einfügen · Menü-Taste oder Umschalt+F10 Kontextmenü.

**Texteditor:** Strg+N/O/S neu/öffnen/speichern · Strg+Umschalt+S speichern
unter · Strg+W Dokument schließen · Strg+Q beenden · Strg+Z/Strg+Umschalt+Z ·
Strg+A · Strg+F suchen · Strg+G/Strg+Umschalt+G weiter/rückwärts suchen ·
Strg+H ersetzen · Strg+I gehe zu Zeile · Strg+Alt+Bild↑/Bild↓ voriges/nächstes
Dokument.

**Bildbetrachter:** Strg+O öffnen · Alt+Eingabe Bildeigenschaften · Strg+W
schließen · Strg+Q beenden · Strg+R/Strg+Umschalt+R drehen · +/−
vergrößern/verkleinern · Strg+0 oder 1 Originalgröße · F einpassen · F11
Vollbild · F5 Diaschau · ←/→ voriges/nächstes Bild · Pos1/Ende erstes/letztes
Bild.

**Bildschirmfoto:** Strg+N neues Bildschirmfoto · Strg+S speichern · Strg+C in
die Zwischenablage · Strg+W schließen · Strg+Z rückgängig · Strg+Umschalt+Z
oder Strg+Y wiederholen · Esc Aufnahme oder Werkzeug abbrechen.

**Taschenrechner:** Ziffern und Komma · + − * / % · Eingabe oder = Ergebnis ·
Rücktaste letzte Ziffer · Entf Eingabe löschen (C) · Esc alles löschen (AC) ·
S/Q/R/V Wurzel/Quadrat/Kehrwert/Vorzeichen · Strg+C/Strg+V · Strg+Q beenden.

**Nach Dateien suchen:** Entf Fundstelle in den Papierkorb · Strg+C Pfad
kopieren · Menü-Taste oder Umschalt+F10 Kontextmenü · Esc Suche abbrechen.
