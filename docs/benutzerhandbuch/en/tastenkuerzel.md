# Keyboard shortcuts

[Back to contents](index.md)

**Super+?** opens the program “Tastenkürzel” (Applications → Accessories,
German only). It reads the shortcuts from the window manager configuration of
the running session and shows on two tabs, “Arbeitsfläche” (desktop) and
“Programme” (programs), everything that currently applies. Esc or Ctrl+W
closes it.

“Super” is the Windows key.

## Session and windows

| Shortcut | Effect |
|---|---|
| Print | Screenshot: choose screen, window or area |
| Alt+Print | Screenshot of a window |
| Ctrl+Alt+L | Lock screen |
| Ctrl+Alt+Del | Session dialog (Log Out, Lock Screen, Restart, Shut Down) |
| Super+? | Shortcut overview |
| Super+D | Show desktop: minimise all windows of the current workspace, press again to bring them back |
| Ctrl+Alt+← / → | Workspace left / right |
| Ctrl+Alt+Shift+← / → | Move the active window to the workspace left / right |
| Alt+Tab / Alt+Shift+Tab | Next / previous window |
| Alt+F4 | Close window |
| Super+A | Maximise / restore window |
| Super+F or Alt+F11 | Fullscreen on / off for the active window (covers the panels) |
| Super+←, →, ↑, ↓ | Snap window to the edge |
| Alt+Space | Window menu |
| Super+Return | Open a terminal (labwc default binding) |
| Volume and brightness keys | louder, quieter, mute; brighter, darker (if the hardware reports them) |

## Programs

The program pages list their shortcuts too. In short:

**Desktop:** F2 rename · Ctrl+A select all · Esc clear selection · Ctrl+click
and Shift+click multiple selection.

**Querencia Files:** Ctrl+N new window · Ctrl+T new tab · Ctrl+W close tab ·
Ctrl+Shift+N new folder · Ctrl+X/C/V cut/copy/paste · Ctrl+D duplicate ·
Ctrl+Z/Ctrl+Shift+Z undo/redo · F2 rename · Alt+Return properties ·
Shift+Del delete permanently · Ctrl+K search · Ctrl+L enter location · Ctrl+R
reload · Ctrl+B sidebar · Ctrl+, preferences · Alt+←/→ back/forward · Alt+↑
parent folder · Alt+Home home folder.

**Querencia Terminal:** Ctrl+Shift+T new tab · Ctrl+Shift+W close tab ·
Ctrl+Shift+Q close window · Ctrl+PgUp/PgDn previous/next tab ·
Ctrl+Shift+PgUp/PgDn move tab left/right · Alt+1 to Alt+9 go to tab 1 to 9 ·
Ctrl+Shift+C copy · Ctrl+Shift+V or Shift+Insert paste · Menu key or
Shift+F10 context menu.

**Text Editor:** Ctrl+N/O/S new/open/save · Ctrl+Shift+S save as · Ctrl+W
close document · Ctrl+Q quit · Ctrl+Z/Ctrl+Shift+Z · Ctrl+A · Ctrl+F find ·
Ctrl+G/Ctrl+Shift+G find next/previous · Ctrl+H replace · Ctrl+I go to line ·
Ctrl+Alt+PgUp/PgDn previous/next document.

**Image Viewer:** Ctrl+O open · Alt+Return image properties · Ctrl+W close ·
Ctrl+Q quit · Ctrl+R/Ctrl+Shift+R rotate · +/− zoom in/out · Ctrl+0 or 1
original size · F best fit · F11 fullscreen · F5 slideshow · ←/→
previous/next image · Home/End first/last image.

**Screenshot:** Ctrl+N new screenshot · Ctrl+S save · Ctrl+C copy to
clipboard · Ctrl+W close · Ctrl+Z undo · Ctrl+Shift+Z or Ctrl+Y redo · Esc
cancel capture or tool.

**Calculator:** digits and comma · + − * / % · Return or = result · Backspace
last digit · Del clear entry (C) · Esc clear all (AC) · S/Q/R/V square
root/square/reciprocal/sign · Ctrl+C/Ctrl+V · Ctrl+Q quit.

**Search for Files:** Del move hit to trash · Ctrl+C copy path · Menu key or
Shift+F10 context menu · Esc stop search.
